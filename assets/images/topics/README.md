# Listening topic image set

## Production spec

- 50 square topic-card images for five age groups.
- Runtime format: JPEG, 640 × 640, quality 90.
- Visual language: polished cute 3D animated-film illustration, rounded forms, soft pastel lighting, Vietnamese/East Asian children, centered subject, generous crop-safe margins.
- Images contain no UI copy, logos or watermarks so they can be reused across display languages.
- Age direction:
  - 3–5: preschool proportions, one simple action or object group.
  - 6–7: early-primary children and familiar home/school activities.
  - 8–10: wider hobbies and practical everyday situations.
  - 11–12: preteen school, teamwork, services and city situations.
  - 13–15: teenage proportions and more mature study, social and travel situations.
