# ODM 新设备诊断测试

本测试版本只用于确认新设备的 BLE、HFP/SCO、麦克风、扬声器和物理按键兼容性。诊断报告不会保存录音、语音转写、账号令牌或后端请求内容。

## 测试前准备

1. 在手机系统蓝牙设置中完成一次配对。
2. 确认设备的“通话音频”已开启。媒体音频可保持关闭。
3. 打开 HOMI，进入家长设置中的 H20/设备连接区域。
4. 点击“开始记录日志”。

## 必测流程

1. 在应用仍打开时关闭设备，再重新开机，等待 BLE 和 HFP 自动恢复。
2. 检查页面是否同时显示 BLE 已连接及 HFP 已连接/已选择。
3. 执行扬声器测试，确认声音从设备扬声器播放。
4. 执行 5 秒麦克风测试并回放，确认声音来自设备麦克风。
5. 分别操作并停顿一秒：
   - MAIN 短按
   - MAIN 长按
   - Power 短按
   - Volume + 长按
   - Volume - 长按
6. 点击“结束并导出”，将生成的 JSON 文件发送给 HOMI 团队。

## 报告包含

- 手机厂商、型号、Android 版本和应用版本。
- BLE 名称、地址、9E3B UUID、特征属性、广播及连接状态。
- HFP Profile、已连接耳机、可用通信设备、当前音频路由和 SCO 验证结果。
- 每个物理按键的数据包 Raw Hex、长度和应用当前解码结果。
- 扬声器与 5 秒麦克风测试结果。

## 本阶段暂不处理

- 不根据未知数据包执行新按键命令；在协议确认前只记录 Raw Hex。
- 不修改正常课程、翻译或语音助手流程。
- 不尝试通过改名为 H20 解决兼容问题。
- 不要求 SCO 在待机时永久开启；只验证应用发起通信会话时能否开启。
- 不上传用户录音或转写内容用于诊断。
